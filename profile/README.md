# xto.email

> **An address that only works for the one sender it was made for.**

Email aliases were supposed to protect you, and in a small way they do — until the address leaks, gets sold, or quietly becomes another channel for the very spam it was meant to deflect. The flaw is structural: a normal alias accepts mail from anyone. The work here closes that hole at the root with an address that is cryptographically bound to a single sender, useless to everyone else, and switched off the instant you no longer want it.

Each alias is derived for exactly one sender domain, and it is only granted when that domain can actually prove it is who it claims to be — no proof, no alias, no exceptions. When you're done with it, revocation happens far below the inbox, at the naming layer of the internet itself: a retired address simply stops existing, so unwanted mail is turned away before it ever reaches a mail server. The security floor is the same for everyone and is never quietly lowered.

The result is an inbox where every address has exactly one rightful sender, leaks are inert, and "unsubscribe" is replaced by something that actually works — making the address vanish.
